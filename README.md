# ProMedic Clinical

Clinical Drug Reference - Medical drug information application.

## Description

Clinical Companion is a medical drug reference application providing healthcare professionals with quick access to drug information, interactions, and clinical guidelines.

## Deployment

- **URL:** https://clinical.promedic1.com
- **Server:** promedic1.com (46.62.228.173)

## Features

- Drug reference database
- Clinical guidelines
- PWA support (offline capable)
- Responsive design

## Structure

- `index.html` - Main application entry
- `assets/` - JS/CSS bundles and static assets
- `sw.js` - Service Worker for PWA functionality
- `manifest.webmanifest` - PWA manifest

## Tech Stack

- React SPA
- Vite build tool
- PWA enabled
